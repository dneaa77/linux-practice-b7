# Практическая работа №7

## Тема

Межпроцессное взаимодействие (IPC):
FIFO, Unix-сокеты, Shared Memory и Pipe.

## Цель работы

Изучить механизмы межпроцессного взаимодействия в Linux,
реализовать обмен данными между процессами и сравнить
производительность передачи больших массивов.

## Задание 1. FIFO

Реализован клиент-сервер для вычисления арифметических выражений.

Сервер получает запросы через именованный канал FIFO,
вычисляет выражение и отправляет ответ через второй FIFO.

Клиенты обслуживаются последовательно.

Проверены арифметические выражения и обработка ошибок.

Файлы:
- fifo/server.py
- fifo/client.py

## Задание 2. Unix-сокеты

Реализован клиент-сервер на основе socket.AF_UNIX.

Сервер принимает соединения и создаёт отдельный процесс
для обработки каждого клиента.

Проверена обработка нескольких одновременно запущенных клиентов.

Файлы:
- unix_socket/server.py
- unix_socket/client.py

## Задание 3. Shared Memory и Pipe

Создан массив из 10 000 000 целых чисел типа int64.

Массив передаётся между процессами двумя способами:
- multiprocessing.shared_memory;
- multiprocessing.Pipe.

Для обоих способов проверяется контрольная сумма данных.

Время измеряется с помощью time.perf_counter().

Результаты приведены ниже.

| Механизм | Объём данных | Время передачи |
|---|---|---|
| Shared Memory | 76.29 MiB | Указать измеренное время |
| Pipe | 76.29 MiB | Указать измеренное время |

## Задание 4. Сравнение механизмов IPC

| Механизм | Нужна ли синхронизация со стороны программиста | Объём данных | Время передачи |
|---|---|---|---|
| FIFO | Для согласования запросов и ответов может потребоваться | Зависит от объёма и числа сообщений | Измерить отдельно |
| Unix-сокет | Для каждого соединения обычно отдельная синхронизация не нужна | Зависит от объёма сообщений | Измерить отдельно |
| Shared Memory | Да, если процессы одновременно обращаются к изменяемым данным | 76.29 MiB в эксперименте | Указать измеренное время |
| Pipe | Для простого обмена через send/recv отдельная синхронизация обычно не нужна | 76.29 MiB в эксперименте | Указать измеренное время |

## Вывод

В ходе работы были реализованы механизмы IPC в Linux.

FIFO использовался для последовательного обмена запросами и ответами.

Unix-сокеты позволили организовать локальное клиент-серверное
взаимодействие с отдельным процессом для каждого клиента.

Shared Memory предоставила общий участок памяти для передачи
массива между процессами.

Pipe использовался для передачи массива через канал
между процессами.

Фактическое время передачи Shared Memory и Pipe зависит
от оборудования, операционной системы и реализации программы.
